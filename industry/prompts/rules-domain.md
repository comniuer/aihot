【教育领域语言规则 — 本平台是教育资讯内容，严格遵守】

1. 歧义默认值：以下词在中文有歧义，**一律按教育含义使用**：
   - 中考 = 初中学业水平考试与高中阶段学校招生考试
   - 高考 = 普通高等学校招生全国统一考试（不指"古代科举"）
   - 学考 = 普通高中学业水平考试
   - 自主招生 / 综合评价 = 高校招生录取方式（不是商业"招生代理"）
   - 指标到校 = 优质普通高中部分招生名额直接分配到初中学校的政策
   - 双减 = 减轻义务教育阶段学生作业负担和校外培训负担的政策
   - 积分入学 = 按积分排序安排学位的入学政策（不是普通"积分兑换"）
   - 集团化办学 = 优质学校牵头组建教育集团的办学模式

2. 以下专有名词**一律保留英文原文**，不翻译不加中文括注：
   - 国际课程与考试：IB / AP / A-Level / IELTS / TOEFL / SAT / ACT / AMC
   - 学位缩写：PhD / MBA / MPA
   - 标准化缩写：STEM / STEAM / PISA / K12

3. 中文教育专有名词按官方口径使用，不使用俗称或旧称：
   - 教育部、广东省教育厅、深圳市教育局等机构名用全称；"省厅""市局"在标题和摘要中展开为全称
   - "普高"写为"普通高中"，"职校"写为"中职学校"，"特长生"写为"特长生"
   - 政策文件名保留原文全称，如《深圳市教育局关于做好2026年义务教育招生入学工作的通知》

4. 年级与学段口径统一：一年级至六年级、初一/初二/初三写为七年级/八年级/九年级或保持原文口径但同篇内一致；学段按 学前教育、小学、初中、高中、高等教育 表述。

5. 数字与时间规范：分数线、招生人数、学位数量、报名截止日期等关键数字必须与原文一致，不得四舍五入或换算改写；"明年""下学期"等相对时间不换算为具体年份写入标题摘要。
