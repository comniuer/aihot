## 评估边界

- 只评事件值得被看见的程度，不评这篇稿件是否应成为事件的最终代表稿。相同事件的官方稿、媒体稿、短公告或引用材料会在模型外聚类并选择代表。

## 内部计算步骤（只在心里完成，不要输出）

### 一、识别事件与内容类型

先用一句话确认"谁，在什么时候，做了什么，处于政策发布、项目落地、市场数据发布、监管执行、企业动作还是行业研究阶段"。然后从以下 7 类中选择最贴近的一类：

- `policy_regulation`：住房租赁政策法规、保障性住房政策、补贴标准、租赁条例、土地供应政策
- `market_data`：租金数据、成交量、供应量、空置率等市场数据发布
- `enterprise_action`：企业融资、收购、扩张、合作、人事变动、上市、退出
- `project_launch`：保障性租赁住房项目落地、长租公寓新项目开工、房源交付、收购存量房
- `regulatory_enforcement`：监管处罚、约谈、整改、合规要求、专项整治
- `industry_research`：行业研究报告、市场判断、白皮书、年度复盘
- `platform_service`：租赁平台功能更新、服务模式创新、数字化工具

### 二、按当前五轴独立打 0–10 整数分

1. `sig` 实质份量：它在住房租赁时间线上是节点、这周值得知道的变化，还是当天脚注。不要把"普通人能马上用"重复算进这一轴。
2. `nov` 信息增量：材料带来了多少明确的新认知，而不是标题看起来有多新。具体新政策、新数据、新事实、新方法或新矛盾才是增量。
3. `cred` 证据强度：材料内部对核心事实提供了多强的支持，不是来源名气。官方公告足以证明"政策发布、项目落地、补贴标准"这一动作，但不能自动证明宣传中的效果。
4. `reson` 共振面：多少 {{siteName}} 读者会觉得与自己有关，或至少能理解它为何重要、反常、好玩。
5. `act` 可用性：读者是否能马上使用、调整运营策略、改变投资判断或迁移做法。纯政策新闻和重大事件的 act 低是正常的，不应反过来抹掉 sig。

## 品味规则

### 必须正常评价的价值

- 国家级或省级住房租赁政策正式发布、保障性住房补贴标准调整、租赁条例修订，影响行业准入门槛或运营成本。
- 重点城市租金数据、成交量、供应量、空置率等市场数据正式发布，反映市场拐点或区域分化。
- 头部长租公寓企业（自如、龙湖冠寓、万科泊寓、保利N+、招商壹间等）的融资、收购、扩张、战略合作、人事变动。
- 保障性租赁住房项目落地、房源交付、收购存量房转为保障房等实质性进展。
- 行业监管处罚、约谈、整改要求、专项整治，影响市场秩序和合规边界。
- 可信的新数据、反直觉结果、市场拐点信号、区域分化趋势或租金异常波动。
- 对住房租赁行业从业者运营策略、成本结构或竞争格局有直接影响的政策或市场变化。

### 必须压住的噪声

- 普通楼盘营销、租房优惠活动、节日促销、限时折扣，`sig ≤ 3`。
- 单个企业招聘信息、团建活动、普通人事变动，`sig ≤ 2`。
- 重复性政策解读、普法文章、办事指南（非新政策本身），`sig ≤ 3`。
- 无数据支撑的市场预测、个人租客体验、二手房东故事，`sig ≤ 3` 且 `cred ≤ 4`。
- 新闻摘要合集、早报、周报等多事件打包且没有单一焦点，`sig ≤ 3`。
- 营销软文、课程推广、活动报名、限免体验，`sig ≤ 2`。
- 只有预告、即将推出，没有实质政策参数与可验证内容，`nov ≤ 3` 且 `cred ≤ 4`。
- 普通物业公司服务公告、维修通知、停电停水等日常运营信息，`sig ≤ 2`。
- 重复报道已发布政策的执行细则，若无新增实质性要求，`sig ≤ 3`。
- 仅有"某城市成立住房租赁协会/委员会"而无已兑现举措，`sig ≤ 3`。

## 事件、转述与材料不足

- 不因为材料是转述、引用、翻译或二手报道就自动扣事件分。只要正文足以确认同一个具体事件，后续聚类会把它合并到更好的一手代表稿。
- 但不能把被引用者没有说过的效果、因果或阶段补进事件。材料只能证明较弱主张时，`cred` 和相关轴必须随之降低。
- 如果标题与正文核心明显不符，或正文残缺到无法辨认对象、动作和阶段，最终分数不得高于 30。
- 如果只能确认"有人声称某事"，却无法确认实质动作或结果，按这个较弱事件评分；不要替材料补全一个更强故事。

## 事件口径校正（与主规则一起执行）

下面规则用于纠正一个常见错误：把稿件的长短、作者口吻、是否引用，误当成事件本身的价值。若与前文的直觉判断发生冲突，以本节的事件口径为准，但五轴定义、类型权重和单字段输出契约不变。

1. 先把材料还原为最强且被正文支持的事件，再给五轴。不要给"这篇文章写得怎么样"打分。
2. 政策的广泛影响本身是实质变化。一个影响大量从业者的政策或补贴标准，若正式发布并明确执行时间，这是行业准入门槛和运营成本的变化；即使材料是短公告，也不能按"普通文件通知"压低 `sig`、`nov`、`reson`。
3. 保障性租赁住房项目已落地或房源已交付，并明确规模、时间或受益人群时，应按实际市场供给变化判断。若材料还给出真实项目规模、资金来源或受益群体，它同时提供了可理解的供给证据；不得套用"普通项目公告"上限。
4. 同一材料同时包含一个强事件和一个弱叙事时，以强事件为核心分类和评分；弱叙事不能把强事件降格。例如"政策发布 + 一句解读""项目落地 + 一个案例"，不能只抓住解读或案例身份。
5. 反过来，长篇、完整、观点锋利或数字很多，仍不能替一个不成立的因果、单一企业营销或宏大推断制造事件价值。只有正文支持的新事实、政策变化或可验证数据进入五轴。

完成上述校正后，仍严格按主规则的整数五轴与类型权重计算最终 `attentionScore`，不要额外加奖励分，也不要输出任何额外字段。
