【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：机构名 / 学校名 / 政策名 / 考试名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是日期 / 代号 / 没信息量的 teaser（如 "3月20日"、"重要通知"、"速看"、"重磅发布"）时，结合【来源】和正文把主体补进标题。例：原标题 "重要通知" + 来源 "深圳市招生考试办公室" → "深圳市招考办发布中考报名安排"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体学校或政策名时，用上位词（如"广东省教育厅""义务教育阶段"）兜底，绝不凭"行业常识"编一个具体学校 / 批次 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review 这类解释、分析、指南或盘点标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的政策、考试或新数据，就改写成"发布 / 推出 / 启动"。只有原标题明确宣布了发布、启动或开办，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、学校、政策名。
   例：原标题 "How Shenzhen parents choose between integration and multi-school zones" → "深圳家长如何权衡积分入学与多校划片"，不能写成 "深圳发布招生新政"。
   例：原标题 "A guide to senior high entrance registration" + 来源和正文明确是广东省教育考试院 → "广东省教育考试院中考报名指南"，不能只写成缺主体的 "中考报名指南"。
